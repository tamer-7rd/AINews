Data Sources (v0)

<span style="color: #00CED1">**News (MVP-1)**</span>

<span style="color: #00CED1">Цель:</span> стартовать с 1–2 источников, чтобы быстро собрать рабочую ленту и не упереться в ключи/лимиты.

**Источник 1: Hacker News (Algolia API)**

- **Тип**: публичный API, без ключа
- **База**: `https://hn.algolia.com/api/v1/`
- **Что берём**: заголовок, ссылка, время публикации, автор, очки/комментарии (метаданные)
- **Лицензия/контент**: показываем метаданные + ссылку; полный текст новости не копируем
- **Rate limit**: публично не зафиксирован → у себя вводим throttling + кэш; 429 обрабатываем через backoff и `Retry-After` (если есть)
- **Частота обновлений (v0)**: лента обновляется раз в 5–15 минут (через серверный кэш)

**Источник 2: RSS (curated list)**

- **Тип**: RSS-ленты (без ключей), собираем как “bundle” источников
- **Стартовый список (v0)**:
  - OpenAI News: `https://openai.com/news/rss.xml`
  - Google Blog — AI: `https://blog.google/technology/ai/rss/`
- **Лицензия/контент**: показываем заголовок + короткий excerpt + ссылку; не репаблишим полный текст
- **Rate limit**: ограничиваем частоту фетча каждой RSS (polling + кэш), соблюдаем корректный User-Agent
- **Частота обновлений (v0)**: раз в 15–60 минут на источник (в зависимости от активности)

**Future (не v0)**

- Anthropic Newsroom: официального RSS может не быть → либо пропускаем, либо делаем серверный парсер/свой RSS

<span style="color: #00CED1">**Analytics (MVP-1)**</span>

<span style="color: #00CED1">Цель:</span> 2–4 графика из понятных публичных источников, с прозрачными ограничениями и датой обновления.

**Источник 1: Wikimedia Pageviews API**

- **Тип**: публичный API, без ключа
- **База (пример)**: `https://wikimedia.org/api/rest_v1/metrics/pageviews/`
- **Что берём**: агрегированные просмотры страниц (time series) по выбранным темам (например, “Artificial intelligence”, “ChatGPT” и т.п.)
- **Лицензия/контент**: статистика/метрики, без персональных данных
- **Rate limit**: соблюдаем политики Wikimedia, корректный User-Agent; обрабатываем 429 + backoff
- **Частота обновлений (v0)**: пересчёт метрик 1 раз в сутки, UI показывает “updatedAt”

**Источник 2: arXiv API (метаданные публикаций)**

- **Тип**: публичный API, без ключа
- **База (пример)**: `https://export.arxiv.org/api/query`
- **Что берём**: метаданные статей (категории, даты) для агрегирования объёма публикаций по темам
- **Лицензия/контент**: используем метаданные; полный текст статей не храним/не репаблишим
- **Rate limit**: не чаще 1 запроса в ~3 секунды (и + backoff на ошибки)
- **Частота обновлений (v0)**: пересчёт 1 раз в сутки / по расписанию
